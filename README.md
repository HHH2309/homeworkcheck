# 🎲 英语作业每日抽查 - 公平性说明

你好！这是一份给所有被“幸运女神”眷顾的同学看的说明书。

你可能因为名字出现在网页上而感到“不幸”，或者怀疑是不是有人在后台暗箱操作。为了消除大家的疑虑，这里用最简单的人话解释一下这个网页是如何工作的，以及为什么它是**绝对公平**的。

## 1. 它是怎么抽签的？（核心原理）

这个程序并没有一个坐在电脑后面的人在手动点名字。它完全依靠**数学**和**日期**来运行。

你可以把它想象成一个 **“每天只变一次的超级计算器”**：

1.  **输入日期**：程序每天起床第一件事，是看一眼日历，比如今天是 `2024-02-18`。
2.  **变成数字**：它把这个日期变成一串极其复杂的数字（这叫“随机种子”）。
3.  **洗牌**：它把全班同学的名字写在扑克牌上，然后用上面那串数字作为规则来洗牌。
    *   *重点来了：* 因为每天的日期是固定的，所以那一天的“洗牌手法”也是固定的。
4.  **发牌**：洗完牌后，拿出最上面的 6 张，这就是今天的倒霉...哦不，幸运名单。

**结论**：只要日期不变，算出来的结果就永远不会变。这就是为什么你疯狂刷新网页，名单也不会变的原因。这防止了有人通过反复刷新来“刷掉”自己的名字。

## 2. 开发者能作弊吗？

**不能。**

为了保证公平，这个网页采用了以下三个机制：

*   **代码开源 (Open Source)**：
    *   这意味着这个网页的“菜谱”是公开的。任何懂一点点电脑知识的人（比如隔壁班的黑掉的低客，或者大学里的哥哥姐姐）都可以查看所有的代码，检查里面有没有写类似 `if (name == "王小明") { protect() }` 这种“保护代码”或者“针对代码”。
    *   你可以点击网页底部的 [公平性保障] 链接查看源码。

*   **第三方公正 (Cloudflare)**：
    *   这个网页不是运行在班长或者课代表的私人电脑上的，而是运行在 **Cloudflare**（一家全球知名的网络安全公司）的服务器上。
    *   一旦代码上传，开发者也无法在不留痕迹的情况下偷偷修改当天的结果。

*   **全班统一**：
    *   任何人在任何时间、任何地点（只要时区一样）打开这个网页，看到的名单都是一模一样的。

## 3. 为什么它知道我以前被抽过几次？

你可能会问：“网页也没让我登录，它怎么知道我历史被抽中过几次？”

其实网页**没有记忆**。它不需要数据库来“记住”你。

每次你打开网页，程序都会像闪电侠一样，瞬间做一件事：
1.  从 `2026-02-11`（开始统计的那天）开始。
2.  算出那天的名单，记一笔。
3.  跳到第二天，算出那天的名单，记一笔。
4.  ……
5.  一直算到今天。

它通过**重演历史**来算出每个人被抽中的总次数。这保证了数据绝对真实，不会因为服务器坏了或者有人改数据而丢失。

## 4. 常见问题 (Q&A)

**Q: 为什么我感觉我总是被抽中？**
A: 这就是纯粹的随机概率（玄学）。就像抛硬币，虽然正反面概率各 50%，但完全可能连续 5 次都是正面。程序使用的是经过科学验证的随机算法，长期来看（比如一学期），大家的次数会趋于平衡，但在短期内，连中是有可能的。

**Q: 下面的“历史统计”列表为什么每次刷新顺序都不一样？**
A: 统计的**次数**是准确的，我们在展示时特意**按被抽取的次数排列顺序**。你只需要关注你名字后面的数字即可。

**Q: 如果周末或者放假怎么办？**
A: 程序是一个无情的机器，它每天都会算出一份名单。如果是节假日，大家都不用交作业，那天的名单自然就作废了，大家忽略即可。
